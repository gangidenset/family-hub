# 05. 画面設計

コンセプト: **シンプル・清潔感・安心感**。片手（親指）で完結する操作を基本とします。

## 1. ナビゲーション

```
┌───────────────────────────┐
│ FamilyHub     [同期●] [⚙] │ ← ヘッダー: 同期状態は常時表示
│                           │
│        (各画面の内容)       │
│                           │
│                      [＋]  │ ← 追加ボタン (FAB) は右下・親指の届く位置
├───────────────────────────┤
│ 🏠    🛒    📅    ✅    📝  │ ← 下部タブ 5 つ
│ホーム 買い物 予定 タスク メモ │
└───────────────────────────┘
```

- 下部タブ: ホーム / 買い物 / 予定 / タスク / メモ（使用頻度順に配置）
- 家族メンバー・データ管理・設定はヘッダー右の ⚙ から（使用頻度が低いため）
- 入力フォームは画面下からのボトムシートで開く（親指で届く・元の画面の文脈を保つ）
- 画面遷移は最大 2 階層。戻る操作は左上の「＜」と OS の戻るジェスチャー両対応

## 2. 画面一覧

### ① ホーム
- 今日の日付・挨拶
- **直近の予定**（今日・明日、最大 3 件）→ タップで予定画面
- **未完了タスク**（期限切れを強調、自分の担当を先頭、最大 5 件）→ その場で完了チェック可
- **買い物リスト概要**（リストごとの未購入件数）
- **ピン留めメモ**（最大 2 件）
- 同期状態カード（最後に同期した家族端末と時刻。未同期の変更がある場合は「同期する」ボタン）
- 初回起動時は「家族グループを作る / 家族に参加する」のオンボーディング

### ② 買い物リスト
- 上部: リスト切替（横スクロールのチップ: 「スーパー」「ドラッグストア」＋追加）
- 項目はカテゴリー別にグループ表示（野菜・肉魚・日用品…）
- 行: [チェック] 商品名 ×数量 ・ メモ（1 行）
  - チェック: 行の左側全体をタップ領域に（48px 以上）。購入済みは取り消し線＋下部の「購入済み」セクションへ
  - 長押し → ドラッグで並び替え / スワイプ → 削除（取り消し可能なトースト）
- 追加: FAB → ボトムシート。商品名入力欄に**購入履歴からの候補**を表示（よく買う物をワンタップ追加）
- 「購入済みをまとめて削除」ボタン
- 購入履歴画面（リスト右上メニュー）: 日付別一覧

### ③ 共有メモ
- ピン留めメモを上部に固定、他は更新日時の新しい順
- カテゴリー絞り込みチップ
- カード: タイトル・本文 2 行・更新日時（「3 時間前・母」）
- 編集画面: タイトル / 本文（自動保存。「保存」ボタン不要で安心感のため保存済み表示）
- 競合がある場合は「競合した編集があります」バナー → 両方の内容を並べて選択

### ④ 家族カレンダー
- 月表示（予定がある日にカテゴリー色のドット）＋ 下に選択日の予定リスト
- 「今日」へ戻るボタン
- 予定行: 時刻（終日）・タイトル・参加メンバーのアイコン
- 追加/編集: タイトル / 終日スイッチ / 開始・終了（OS ネイティブの日時ピッカー）/ 参加メンバー（アイコン複数選択）/ カテゴリー / 場所 / メモ

### ⑤ タスク管理
- フィルタ: 「未完了」（既定）/「自分」/「完了済み」
- 並び: 期限切れ → 今日 → 期限あり → 期限なし
- 行: [チェック] タイトル ・ 担当者アイコン ・ 期限（期限切れは赤ではなく注意色＋アイコンで色覚多様性に配慮）
- 追加: タイトル / 担当者（家族アイコンから選択）/ 期限（「今日」「明日」「週末」のクイック選択＋日付）

### ⑥ 家族メンバー管理
- メンバー一覧（名前・色・アイコン・この人の端末一覧）
- メンバー追加（人の登録。端末を持たない子どもも登録可能＝担当者・参加者として使える）
- **端末を家族に追加** → ペアリング画面（QR 表示 / QR 読み取り）
- 端末の削除（失効）→ 確認画面で「すでにこの端末にあるデータは消えません」と明記

### ⑦ データ管理・設定
- 同期: 「今すぐ同期」/ 同期履歴 / 代替手段「ファイルで同期」
- バックアップ: 書き出し / 復元（確認画面あり）/ 全データ削除（グループ名の入力で確認）
- 表示: テーマ（自動/ライト/ダーク）/ 文字サイズ（標準/大/特大）
- アプリについて: バージョン / 利用規約 / プライバシーポリシー / オープンソースライセンス

## 3. 同期 UI（Phase 3）

同期は以下の 4 状態で表示します（ヘッダーのアイコン＋色＋文字。色だけに頼らない）。

| 状態 | 表示 |
|---|---|
| 同期済み | ✓ 「同期済み・5 分前（父の Android）」 |
| 未同期の変更あり | ↑ 「未送信の変更 3 件」 |
| 同期中 | ⟳ 「同期中… 120/300 件」 |
| 失敗 | ! 「同期できませんでした」＋理由＋「再試行」/「ファイルで同期」 |

## 4. デザイントークン（初期値）

| トークン | ライト | ダーク | 用途 |
|---|---|---|---|
| `--bg` | `#F7F8FA` | `#111315` | 背景 |
| `--surface` | `#FFFFFF` | `#1B1E21` | カード・シート |
| `--text` | `#1C2024` | `#ECEEF0` | 本文 |
| `--text-sub` | `#5B636B` | `#A3ABB3` | 補足 |
| `--primary` | `#2F7D6D` | `#5FBFA9` | 主要操作（落ち着いた緑青: 安心感） |
| `--warn` | `#B35C00` | `#F0A04B` | 期限切れ・注意 |
| `--danger` | `#B3261E` | `#F2B8B5` | 削除 |
| `--radius` | 14px | | 角丸 |

- 文字: システムフォント（`-apple-system, "Hiragino Sans", "Noto Sans JP", sans-serif`）。外部フォントは読み込まない（オフライン・プライバシー）。本文 17px、行間 1.6。
- タップ領域: 最小 48×48px、主要ボタンは高さ 52px。
- セーフエリア（ノッチ・ホームインジケーター）に `env(safe-area-inset-*)` で対応。
- アニメーションは 200ms 以内、`prefers-reduced-motion` で無効化。
