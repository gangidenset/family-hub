# Phase 2〜5 完了報告

日付: 2026-11-08 (Phase 1 は [phase1-report.md](./phase1-report.md))

## Phase 2: 基本機能

**実装内容**
- Vite + React 19 + TypeScript (strict, `noUncheckedIndexedAccess`) のプロジェクト構成
- データ層: Dexie (IndexedDB) スキーマ、zod による全エンティティのスキーマ、Repository (書き込み + 操作ログを同一トランザクション)、HLC、並び順キー
- UI: 下部タブ・ボトムシート・確認ダイアログ・元に戻せるトースト、ライト/ダーク/自動、文字サイズ 3 段階、セーフエリア対応
- 画面: オンボーディング / ホーム / 買い物リスト (複数リスト・カテゴリー・数量・メモ・並び替え・購入済み・購入履歴・よく買う物) / 共有メモ (自動保存・ピン留め・カテゴリー) / カレンダー (月表示・終日・複数日・参加メンバー) / タスク (担当・期限・クイック期限・絞り込み) / 家族メンバー / 設定 / カテゴリー管理
- PWA: manifest、Service Worker による全アセットのプリキャッシュ、更新通知

## Phase 3: 家族共有

**実装内容**
- QR コード表示 (qrcode) と読み取り (BarcodeDetector → 非対応環境は jsQR)、カメラが使えない場合のコード貼り付け
- WebRTC DataChannel (STUN/TURN なし)、接続情報の圧縮コーデック、大きなメッセージの分割と背圧制御
- ペアリング: 確認コード (SAS) の照合後にグループ鍵を受け渡し、端末の所有メンバーを選択
- 同期プロトコル: HMAC 相互認証 (DTLS フィンガープリントに束縛)、AES-GCM 暗号化フレーム、バージョンベクタによる差分交換、鍵更新の配布
- 競合解決: フィールド単位 LWW、メモ本文・タイトルの競合保持と解決 UI
- 同期状態: ヘッダーの状態表示 (未送信件数 / 最終同期)、同期履歴、エラー理由の表示と再試行
- 代替手段: 暗号化同期ファイル (共有シート / ダウンロード)
- 端末の失効と鍵更新、メンバー削除

## Phase 4: 品質向上

**実装内容**
- バックアップ: 平文 / パスフレーズ暗号化 (PBKDF2 60 万回 + AES-GCM, 鍵を含む)、チェックサム、厳格検証、プレビュー付き確認画面、オンボーディングからの復元
- 全データ削除 (グループ名入力で確認)
- セキュリティ: 本番ビルドに CSP を埋め込み (`connect-src 'self'` 等)、安全な JSON パース、全入力の zod 検証、外部リクエスト 0 件を E2E で確認

**E2E で見つけて修正した不具合**
1. フォームの保存で未変更の項目まで書き込み、他端末の同時編集を古い値で上書きしていた (同期設計上の重大な不具合) → 変更されたフィールドのみ記録
2. Service Worker が一度も登録されていなかった (登録処理が load イベント後にマウントされていた) → オフライン起動できない状態だった
3. `groups` テーブルのインデックス不足でグループ作成直後に例外
4. `<label>` 内のボタン群で、見出しタップ時に先頭のボタンが押される
5. 一覧の矢印アイコンの巨大化、読み込み中に「空です」が一瞬表示される
6. 同期完了後の画面遷移の競合

**テスト結果**: 単体・結合 35 件 / E2E 8 件 すべて成功 (詳細は [testing.md](./testing.md))

## 残課題 (優先度順)

| # | 課題 | 理由 |
|---|---|---|
| 1 | **Android・iPhone 実機での検証** ([testing.md](./testing.md) §3) | この開発環境に実機・WebKit がないため未実施。特に iOS⇔Android の WebRTC 接続と家庭用 Wi-Fi での mDNS 解決が最大のリスク |
| 2 | Capacitor ネイティブプロジェクトの生成とビルド | Android SDK / Xcode が必要 |
| 3 | ネイティブ版での LAN 自動発見 (Bonjour/NSD) | 毎回の QR 交換をなくし、製品価値を大きく高める |
| 4 | 法務文書の確定・運営者情報の記入 | 公開に必須 |
| 5 | ESLint の導入、CI (GitHub Actions) での自動テスト | 品質維持 |
| 6 | i18n (英語版) | 海外販売時 |
| 7 | トゥームストーン・操作ログの長期的な圧縮 | 数年単位の利用でのデータ量抑制 |
| 8 | 予定の繰り返し・リマインダー通知 | ネイティブ版で検討 |
| 9 | アイコン・スクリーンショットの最終デザイン | 現在は仮デザイン |
