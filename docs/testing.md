# テスト計画と結果

> **方針**: 実際に実行して確認したものだけを「確認済み」と書きます。

## 1. 自動テスト

### 実行方法

```bash
npm test            # 単体・結合テスト (Vitest + fake-indexeddb)
npm run test:e2e    # E2E (Playwright。本番ビルドを vite preview で配信して実行)
```

### 単体・結合テスト (35 件, 2026-11-08 全件成功)

| ファイル | 内容 |
|---|---|
| `tests/unit/hlc-sortkey.test.ts` | HLC の単調性・時計ずれ時の挙動・未来すぎる時刻の拒否 / 並び順キーの生成 |
| `tests/unit/repo-merge.test.ts` | 操作ログ連番、入力検証、双方向マージの収束、別フィールド同時編集、削除の伝播、冪等性、メモ本文の競合保持、順序どおりの編集を競合扱いしない、不正・別グループ・プロトタイプ汚染データの拒否、時計ずれの拒否、**フォームが未変更項目を書き込んでも相手の変更を上書きしない** |
| `tests/unit/protocol.test.ts` | 認証付き同期、2000 件 + 2 万文字メモの分割転送、鍵違い (auth-failed)、別グループ、失効端末、鍵更新の配布、**通信途中切断からの再同期**、ペアリング (確認コード一致・不一致) |
| `tests/unit/backup-file-codec.test.ts` | バックアップの書き出し/検証/復元、暗号化バックアップ、誤ったパスフレーズ、不正ファイル 7 種の拒否、全削除後の復元、暗号化同期ファイルの冪等な取り込み・改ざん検知、接続コードの往復と不正コード拒否 |

### E2E テスト (8 件, 2026-11-08 全件成功)

環境: Playwright 1.63 / Chromium 1243 (headless) / Pixel 7 エミュレーション / Linux コンテナ

| テスト | 確認内容 |
|---|---|
| グループ作成 → 各機能でデータ登録 → 再起動後もデータが残る | 買い物・タスク・予定・メモ (自動保存・ピン留め)・購入履歴、ページ再読み込み後の保持、コンソールエラーなし |
| ダークモードと文字サイズ | 設定の反映と再起動後の保持 |
| XSS | `<img onerror>` を商品名に入れてもテキスト表示され、スクリプトが実行されない |
| インターネットなしで起動 | Service Worker 登録 → **オフラインで再読み込みして起動**、オフラインでのデータ登録、再起動後の保持、法務ページのオフライン表示 |
| 外部への通信が発生しない | 全画面を巡回して localhost 以外へのリクエストが 0 件、CSP の存在 |
| バックアップ → 全削除 → 復元 | 暗号化/平文の書き出し、不正ファイル・改ざんファイルの拒否 (プレビューが出ない)、全削除、オンボーディングからの復元 (誤ったパスフレーズの拒否) |
| ペアリング → 同期 → 同時編集 → 失敗からの復旧 | **2 つの独立したブラウザコンテキスト間で WebRTC 接続** (STUN/TURN なし)、確認コード一致、オフライン中の同時編集 (同一項目の別フィールド・それぞれの追加) が双方で収束、メモ本文の同時編集で競合表示、不正コードの拒否、誤ったコードの拒否後に再同期成功 |
| 接続タイムアウト → ファイル同期 | 相手が消えた状態でタイムアウト → エラー表示と代替手段の案内 → 暗号化ファイルで同期成功 |

**E2E の制約 (正直な注記)**
- QR コードのカメラ読み取りはヘッドレス環境にカメラがないため、同じ文字列を「コードを貼り付け」機能で受け渡しています。QR の生成・デコード自体は単体テストと Phase 1 の Spike で検証済みですが、**実機カメラでの読み取りは未検証**です。
- 2 つのブラウザコンテキストは同一マシン上で動作しています。実際の Wi-Fi 越しの通信ではありません。
- WebKit (Safari) はこの環境にインストールされていないため、**iOS の動作は自動テストしていません**。

## 2. 要件で指定されたテストケースの状況

| ケース | 状況 |
|---|---|
| インターネットがない状態での起動 | ✅ E2E (Chromium) で確認 / ⬜ 実機未確認 |
| オフラインでのデータ登録 | ✅ E2E で確認 |
| アプリ再起動後のデータ保持 | ✅ E2E (ページ再読み込み) で確認 / ⬜ 実機でのアプリ終了・再起動は未確認 |
| Android と iPhone 間の共有 | ⬜ **未確認** (実機が必要) |
| 同一 Wi-Fi 内での同期 | ⬜ **実ネットワークでは未確認** (同一マシン上の 2 コンテキスト間では ✅) |
| 複数端末で同時に編集した場合 | ✅ 単体 + E2E で確認 |
| 同期失敗時の復旧 | ✅ 単体 (途中切断→再同期) + E2E (タイムアウト→ファイル同期、不正コード→再同期) |
| バックアップと復元 | ✅ 単体 + E2E |
| 不正なバックアップファイルの読み込み | ✅ 単体 (7 種) + E2E (2 種) |
| データ削除時の動作 | ✅ 単体 + E2E (全削除 → オンボーディング → 復元) |
